# Weeping Ghosts Corp Bot — Eve Echoes 🚀

Telegram-бот для корпорации **Weeping Ghosts** по игре **Eve Echoes**.

---

## ✨ Функционал

| Модуль | Команды | Описание |
|---|---|---|
| Регистрация | `/start`, `/register` | Регистрация через скриншот, одобрение администратором |
| Отчёты | `/report` | Сдача скриншота активности (PvP/PvE/Лут), OCR-распознавание и классификация |
| Баланс | `/balance` | Просмотр баланса ISK и истории транзакций |
| Заказы | `/orders`, `/order`, `/create_order` | Список корпоративных заказов, взятие и выполнение |
| Рейтинг | `/pvp_rating`, `/pve_rating`, `/industry_rating` | Таблицы лидеров по PvP, PvE и промышленности |
| Калькуляторы | `/industry_calc`, `/implant_calc` | Расчёт производства по навыкам; прокачка имплантов до 40 уровня |
| Гайды | `/guides`, `/add_guide` | Список гайдов для новичков с категориями |
| Теги | `/my_tag`, `/set_tag` | Роли пилотов и кастомные теги в чате |
| AI-агент | `/ai`, `? вопрос` | Ответы на вопросы об Eve Echoes через OpenAI |
| Новости | `/send_news` | Рассылка новостей в личные сообщения всем участникам |
| Админ-панель | `/admin`, `/balance_adjust` | Управление пользователями, балансом, отчётами |

## 🛠️ Установка

### 1. Требования

- Python 3.11+
- [Tesseract OCR](https://github.com/tesseract-ocr/tesseract) (`apt install tesseract-ocr tesseract-ocr-rus`)

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Настройка

```bash
cp .env.example .env
# Отредактируй .env — обязательно укажи BOT_TOKEN и ADMIN_IDS
```

### 4. Запуск

```bash
python main.py
```

---

## ⚙️ Переменные окружения

| Переменная | Обязательно | Описание |
|---|---|---|
| `BOT_TOKEN` | ✅ | Токен бота от @BotFather |
| `ADMIN_IDS` | ✅ | ID администраторов через пробел |
| `CORP_CHAT_ID` | — | ID группового чата корпорации |
| `OPENAI_API_KEY` | — | Ключ OpenAI для AI-агента |
| `OPENAI_MODEL` | — | Модель OpenAI (по умолч. `gpt-4o-mini`) |
| `DB_PATH` | — | Путь к SQLite БД (по умолч. `data/bot.db`) |
| `TESSERACT_CMD` | — | Путь к исполняемому файлу tesseract |

## 🔐 Права бота в группе

Для полноценной работы бот должен быть **администратором** группы со следующими правами:
- Изменение информации о группе
- Управление администраторами (для установки кастомных тегов)
- Управление участниками
